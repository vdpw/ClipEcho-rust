# ClipEcho Rust archive

This repository is a read-only archive of the original Rust/Tauri 2 + React implementation of ClipEcho. It includes the frontend, Rust backend, resources, tests, documentation, and build workflows needed to understand and reproduce that version. It contains no Swift/AppKit rewrite.

- Archived on: 2026-10-14.
- Original repository: https://github.com/vdpw/ClipEcho.
- Last original Rust commit: `f051c0cb286b9af984f0d392eaeee51a99e1fd5c`.
- The Rust tree at that commit is identical to the Rust tree in ClipEcho main at `1488c04dda5cefb9ddc414f821bf44519b393649`, before the root Swift migration.
- All ancestors of the original Rust commit are preserved. Swift commits, other branches, release tags, generated files, and local clipboard databases are excluded.
- GitHub Actions are disabled. GitHub repository archival makes the repository read-only.

For current development, issues, and releases, use [ClipEcho](https://github.com/vdpw/ClipEcho). Build and runtime instructions below the archive banner in README.md describe this frozen Rust version.
